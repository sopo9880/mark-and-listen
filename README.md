# Mark & Listen

현재 공개 베타는 [v0.1.1.0](https://github.com/sopo9880/mark-and-listen/releases/tag/v0.1.1.0)입니다. 제품 설계, 구현 범위, Windows 실사용 결과와 다음 작업은 [통합 설계 및 인수인계](docs/design-handoff.md)에 정리했습니다. 베타 설치 안내는 [v0.1.1.0 안내](BETA-0.1.1.0.md)를 참고하세요.

아래는 **0.0.0.2 개발 빌드의 기존 사용 안내**입니다.

토익 연습용 데스크톱 개발 빌드입니다. 소스 폴더에서는 브라우저로 실행할 수 있고 Windows x64 실행 파일은 이 소스와 별도로 배포합니다. 공식 TOEIC 시험과 관계없이 독립적으로 만든 문제입니다.

## 실행 (소스)

1. 압축을 풀고 Node.js 22 이상을 설치하세요. npm 패키지 설치는 필요 없습니다.
2. Windows에서는 `Start-Mark-and-Listen.cmd`를 더블 클릭하세요. 또는 폴더에서 `npm start`를 실행하세요.
3. 브라우저에 `http://127.0.0.1:4173/`을 여세요. 끝낼 때 실행 창에서 Ctrl+C를 누르세요.
4. 4173 포트가 사용 중이면 PowerShell에서 `$env:PORT=4174; npm start`를 실행하고 주소의 포트도 4174로 바꾸세요.

## 사용법

- **대시보드**에서 최근 원점수, 누적 정답률, LC/RC 정답률, 진행 중인 작은 세트를 확인합니다.
- **시험 연습**에서 기본 세트 또는 **전체 200문항**을 엽니다.
- **기록 · 복습**에서는 과거 세트의 답안과 정답, 오답/미응답, Part별 정답률, 대본과 음원을 확인합니다. 제출은 당시 문항과 성적을 기록하므로 이후 AI 세트를 교체해도 이전 기록이 바뀌지 않습니다. 로컬 저장 공간과 건수 제한에 따라 오래된 기록부터 정리될 수 있습니다.

## 전체 모의고사

- LC Part 1–4 100문항(원본 삽화, 그래픽, 영어 합성 음원 포함)과 RC Part 5–7 100문항(단일·복수 지문)을 오프라인에서 풀 수 있습니다.
- LC 45분 후 RC 75분으로 넘어가며 LC 답안과 음원은 잠깁니다. RC 제한 시간이 끝나면 자동 제출됩니다. 다른 화면, 새로고침, 꺼진 앱에서는 제한 시간이 계속 흐릅니다. 시험에 돌아와 자동 재생이 막혔다면 **듣기 이어서 재생**을 눌러 현재 위치에서 시작할 수 있습니다.
- 전체 시험은 문제 화면에서 답을 선택할 수 없습니다. 오른쪽 OMR에 직접 마킹하고, 같은 마킹을 다시 눌러 지웁니다. Part 버튼과 문항 번호로 이동합니다. LC의 영어 선택지는 Part 1/2에서 시험 중 음성으로만 제공됩니다.
- Part 1은 사진 대신 독자 제작 삽화를 사용합니다. 공식 시험 음원, 공식 환산 점수, 색인형 전문 출제 검수는 제공하지 않습니다.

## 기본 세트

- 인터넷이나 계정 없이 LC Part 2 6문항과 RC Part 5 10문항을 풀 수 있습니다.
- LC 음원 6개는 오리지널 문제를 영어 합성 음성으로 녹음한 파일입니다. 정답과 LC 대본은 채점 뒤 표시됩니다.
- 연습 모드에서는 보기에서 고르면 답안지에도 표시됩니다. 실전 OMR 모드에서는 직접 OMR에 마킹해야 합니다. 이미 마킹한 같은 버블을 다시 누르면 지워집니다.
- 진행 중인 답안과 현재 문항은 같은 브라우저/주소에 저장됩니다. 제출하면 정오표, 섹션별 원점수, 미응답 및 해설을 볼 수 있습니다. 토익 공식 환산 점수는 아닙니다.

## AI 엔진 (선택)

AI 엔진에서 **RC Part 5 문제 3개 만들기**를 누르고 완성되면 **새 문제 열기**를 누르세요. 생성만으로 진행 중인 세트가 사라지지 않습니다. AI 문제는 형식 검사를 거치지만 정답과 문장의 정확성은 검수 전입니다. 만든 RC Part 5 3문항은 JSON으로 저장하고 다시 가져올 수 있습니다. 금번 빌드의 AI 자동 출제는 RC Part 5에 한정되며 아래의 듣기 낭독 기능은 독립입니다.

- **Codex:** 본인의 계정으로 Codex CLI에 로그인한 후 사용하세요. PC에 이미 설치했다면 터미널에서 `codex login`을 실행하세요. 관리형 실행 파일을 설치한 경우 경로 안내는 설치 완료 화면에 표시됩니다. ChatGPT 로그인 상태를 확인하며 API 키나 다른 엔진으로 자동 전환하지 않습니다.
- **GPT:** OpenAI API 키를 입력하세요. ChatGPT 구독과 별개의 API 사용입니다.
- **Gemini:** Gemini API 키를 입력하세요. 키가 속한 Google 프로젝트에 사용량이 반영됩니다.
- 입력한 API 키는 앱이 파일이나 브라우저 저장소에 보관하지 않습니다. 엔진은 사용자가 버튼을 눌렀을 때만 네트워크 호출합니다.

## 듣기 제작

문제 제작의 **듣기 대본 낭독**에서 Gemini Live API를 선택적으로 호출합니다. 사용자가 넣은 영어 대본으로 WAV를 만들고 들어보거나 내려받을 수 있습니다. 작은 기본 세트의 LC 6문항 대본을 수정하지 않고 낭독한 경우에는 그 문항용으로 이 기기에 저장하거나 원래 녹음으로 되돌릴 수 있습니다. 전체 모의고사의 음원은 시험 일관성을 위해 바뀌지 않습니다. Gemini 프로젝트에서 사용 가능한 모델과 API 키가 필요하며, 다른 엔진으로 자동 전환되지 않습니다.

## Codex 런타임 관리

지원 환경에서만 AI 엔진 화면의 설치·확인 버튼이 표시됩니다. 자동 다운로드·업데이트하지 않습니다. 지정 버전 설치, 최신 확인, 명시적 최신 설치, 이전 버전 복원이 관리형 런타임에만 적용됩니다. 시스템 Codex의 자동 업데이트 또는 삭제를 하지 않습니다. 설치한 런타임이 없으면 PATH의 Codex CLI를 사용합니다.

관리형 런타임의 버전 고정, 공식 배포처 조회, 검증 후 전환은 [Canvas Assistant의 엔진 구현](https://github.com/sopo9880/canvas-assistant/blob/012eab5b3a6304270df1a3f900eaad474da01c57/src-tauri/src/engine.rs)을 참고하여 이 앱의 Node.js 구조에 맞게 적용했습니다. 관리형 설치는 Windows x64에 제공합니다.

## 검증 / 범위

`npm test`로 두 단계 시험 시간 및 마킹 제한, 문항 구조와 채점/대시보드, 로컬 서버 및 음원 전송, 공급자/런타임의 모의 경계를 검사합니다. 실제 AI 계정에서의 요청/청구와 Windows 화면 환경은 별도 검증 사항입니다. AI가 듣기·읽기 전 파트의 신규 200문제를 자동 제작하는 기능, 점수 공식 환산, 온라인 동기화는 이번 버전에 없습니다.
